Use animation to improve understanding and interaction, not merely decoration.

Use Motion/Framer Motion for:
- hover states
- page transitions
- modals
- dropdowns
- list changes
- card transitions
- number transitions
- sidebar interactions

Use GSAP selectively for:
- complex timeline animations
- premium hero moments
- workflow visualizations
- approval routing
- warehouse allocation
- major state transitions

Do not use GSAP everywhere.

Animations should be fast, subtle and purposeful.

Typical durations:
- micro interaction: 120–180ms
- standard interaction: 180–250ms
- major transition: 300–500ms

Respect prefers-reduced-motion.
