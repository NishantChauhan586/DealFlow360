Build DealFlow360 interfaces with a premium, minimal enterprise SaaS aesthetic.

Design principles:
- modern
- minimal
- professional
- responsive
- accessible
- fast
- lightweight
- strong typography
- generous whitespace
- clear visual hierarchy
- subtle borders
- restrained shadows
- purposeful depth

Use inspiration from Linear, Stripe, Vercel, Raycast and high-quality Awwwards interfaces, but maintain a unique DealFlow360 identity.

Avoid:
- generic dashboard templates
- excessive glassmorphism
- excessive gradients
- neon-heavy interfaces
- oversized cards
- excessive rounded containers
- visual clutter
- unnecessary decorative elements
